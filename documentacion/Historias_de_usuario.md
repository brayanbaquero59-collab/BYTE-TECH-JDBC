# Historias de usuario – BYTE TECH

**HU01 – Registrar producto**  
Como administrador de inventario, quiero registrar un computador o accesorio con sus datos principales para mantener actualizado el inventario.  
Criterios: los campos obligatorios deben estar completos; precio y stock no pueden ser negativos; el sistema confirma el registro.

**HU02 – Consultar inventario**  
Como administrador, quiero visualizar los productos registrados para conocer la disponibilidad de BYTE TECH.  
Criterios: se muestra una tabla con identificador, nombre, categoría, marca, precio y stock.

**HU03 – Buscar producto**  
Como administrador, quiero filtrar productos por nombre, categoría o marca para encontrarlos rápidamente.  
Criterios: el listado se actualiza según el texto de búsqueda.

**HU04 – Actualizar producto**  
Como administrador, quiero seleccionar un producto y modificar sus datos para corregir o actualizar la información.  
Criterios: se requiere una fila seleccionada; los datos deben validarse antes de guardar.

**HU05 – Eliminar producto**  
Como administrador, quiero eliminar un producto que ya no se comercializa para mantener limpio el inventario.  
Criterios: el sistema solicita confirmación antes de eliminar.
